# Build Date Matters: Publication Truncation and Coverage Drift in Patent Combination Indicators

Code to reproduce the tables, figures and reported numbers of the paper *Build Date Matters: Publication Truncation and Coverage Drift in Patent Combination Indicators*.

The paper compares two builds of a Chinese listed-company robotics patent table (CNRDS), two releases of United States granted-patent data (PatentsView), United States pre-grant publications (PatentsView) and Chinese applications from Google Patents Public Data. It traces label changes in a technology-pair recurrence indicator to individual records, compares how pair-level, count and share indicators respond to the build date, and tests a rule for deciding when a recent cohort is complete enough to use.

## Repository layout

```
src/                     analysis scripts (Python)
sql/                     BigQuery query for the Google Patents exports
scripts/                 shell script that builds the PatentsView granted-patent extracts
data/derived/            small derived inputs that cannot be regenerated by the code
results/                 created when you run the scripts (not tracked)
requirements.txt         Python packages and versions
```

## Installation

Python 3.13 was used.

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Run every script with `python3 -I`. Scripts that import shared modules (`recurrence.py`, `publication_truncation_sim.py`, `cohort_trend_and_validation.py`, `firm_regression.py`) find them in `src/` automatically.

## Data

### Licensed data (not included)

The CNRDS exports are subscription data from the Chinese Research Data Services Platform (https://www.cnrds.com). The provider's terms prohibit redistribution, so they are not in this repository. Subscribers need:

| Input | CNRDS table |
|---|---|
| Earlier build | Industrial Robots Research Database (IRRD): listed-company industrial robot patents (Stata file, header dated 2026-05-01) |
| Later build | IRRD: listed-company industrial robot patents (xlsx, members dated 2026-11-11; data member SHA-256 `bfd180212bd4d04b27e7495cdd8bd15c0f0032cb0433d5524a71a982d9f6f5c5`) |
| Firm robot applications | IRRD: listed-company robot patent applications (Stata) |
| Controllers | Equity Research Database (CERD): actual controllers |
| Firm covariates | Financial Statements (balance sheet, income statement), Company Basic Information, firm patent applications |

`build_covariates.py` writes a firm-level file derived from these exports; it is licensed data and must not be shared.

The recovered application publication dates (`Combined_Robotics_Metadata.csv`) were assembled from public bibliographic records. The file is not included here because it lists the patents in the licensed CNRDS table; see the paper's data availability statement.

### Public data

- **PatentsView pre-grant publications** (USPTO Open Data Portal, dataset PVPGPUBDIS, release of 10 April 2026): `pg_published_application.tsv.zip`, `pg_cpc_at_issue.tsv.zip`. Place both in one folder (called `US` below) with an empty subfolder `US/us_analysis/`.
- **PatentsView granted patents** (dataset PVGPATDIS), two releases:

  | File | Release | Bytes | SHA-256 |
  |---|---|---|---|
  | `g_cpc_current.tsv.zip` | internal file dated 2025-03-13 | 485,195,636 | `ef30a75d64b5070c73b1c63ed7997e23954e2cd06299797371f0a24cf5c4c441` |
  | `g_cpc_current.tsv.zip` | released 2026-04-10 | 503,091,774 | `3e117660a3446c5f9efd4fb7e8bcc39200660a9dd057ea9afa3925dbf6ee851b` |
  | `g_application.tsv.zip` | released 2026-04-10 | 71,601,386 | `0dc471ac15dc22cc333a09932ad7e3e4c2380eb165ca9b2819bfdc56ce3c0122` |

  Rename them `g_cpc_current_2025-03.tsv.zip`, `g_cpc_current_2026-04.tsv.zip` and `g_application_2026-04.tsv.zip`, then run `scripts/extract_us_granted.sh <folder>`.
- **Google Patents Public Data** (BigQuery table `patents-public-data.patents.publications`, queried 24 November 2026): run `sql/google_patents_query.sql` and export the result as CSV. Replace `B25J%` with `B23K%` for the held-out field.

## Running

Set the input paths, then run from the repository root. Outputs go to `results/`.

```
mkdir -p results && cd results
SRC=../src
EARLIER="/path/to/earlier_build.dta"
LATER="/path/to/later_build.xlsx"
META="/path/to/Combined_Robotics_Metadata.csv"
SUPPORT=../data/derived/support_dates.csv
CERD="/path/to/controllers.xlsx"
APPS="/path/to/firm_robot_applications.dta"
COV=firm_covariates_2021.csv          # licensed: written by build_covariates.py
US=/path/to/US                        # PatentsView pre-grant zips, with US/us_analysis/
GRANTED=/path/to/granted              # PatentsView granted-patent zips

# CNRDS audit
python3 -I $SRC/recurrence.py "$EARLIER"; python3 -I $SRC/recurrence.py "$LATER"
python3 -I $SRC/publication_truncation_sim.py "$LATER" "$META" $SUPPORT pub_truncation.csv
python3 -I $SRC/cohort_trend_and_validation.py "$EARLIER" "$LATER" "$META" $SUPPORT ds
python3 -I $SRC/build_covariates.py balance/ income/ cbid/ cird/ $COV
python3 -I $SRC/firm_regression.py "$EARLIER" "$LATER" "$CERD" "$APPS" firm_regression_ind.csv $COV main
python3 -I $SRC/cutoff_scan_and_novelty.py "$EARLIER" "$LATER" "$META" $SUPPORT "$CERD" "$APPS" $COV rev
python3 -I $SRC/matched_rates_and_intervals.py "$EARLIER" "$LATER" "$META" $SUPPORT "$CERD" "$APPS" $COV rc
python3 -I $SRC/cluster_bootstrap_and_thinning.py "$EARLIER" "$LATER" r2
python3 -I $SRC/definition_checks.py "$EARLIER" "$LATER" sensitivity_recomputed.csv
python3 -I $SRC/novelty_by_quarter.py "$LATER" novelty_by_quarter_cn.csv
python3 -I $SRC/date_consistency.py "$META" "$EARLIER" "$LATER" date_consistency.csv

# United States pre-grant publications
python3 -I $SRC/us_truncation.py "$US" 2021-06-30 ME
python3 -I $SRC/us_field_lag.py "$US" us_field_lag.csv
for f in B25J A61B G06N H01M; do python3 -I $SRC/rule_forecast.py "$US" rule_forecast_$f.csv $f 2016; done

# United States granted-patent releases
bash ../scripts/extract_us_granted.sh "$GRANTED"
python3 -I $SRC/us_release_comparison.py "$GRANTED/vintage" .
python3 -I $SRC/us_release_gain_sources.py "$GRANTED/vintage" us_vintage_gain_source.csv

# Forecast tests on Chinese data and summaries
python3 -I $SRC/cnrds_rule_forecast.py "$LATER" "$META" $SUPPORT cn_rule_forecast.csv
python3 -I $SRC/cnrds_rule_forecast_bootstrap.py cn_rule_forecast.csv cn_rule_forecast_bootstrap.csv
python3 -I $SRC/cn_google_forecast.py /path/to/cn_b25j_export.csv cn_google_forecast.csv
python3 -I $SRC/cn_google_forecast.py /path/to/cn_b23k_export.csv cn_google_forecast_B23K.csv
python3 -I $SRC/forecast_margin_summary.py forecast_margin_summary.csv
python3 -I $SRC/rule_outcomes_by_set.py rule_outcomes_by_set.csv
python3 -I $SRC/heldout_and_fixed_horizon.py
```
